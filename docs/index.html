常见问题

按踩坑概率排序。

装完菜单还是英文？

99% 是菜单缓存没清。关闭 Autopsy，删除 %LOCALAPPDATA%\autopsy\Cache\dev 下的全部内容，再启动。安装脚本已自动清过一次；如果你之前装过另一个 Autopsy，两者交替使用时需要再清一次。

会影响取证结果吗？

不会。只替换界面文案资源，不触碰任何分析逻辑、数据库结构或解析代码。

个别地方仍是英文？

约 181 条字符串写死在程序代码里（多为日志与异常提示），资源文件改不到，需要改字节码，本版未做。另有 77 条按规范刻意保留英文，如格式模板、字体名、产品名。

Autopsy 升级后还能用吗？

不能直接套用。安装脚本会对每个要改的 layer 做哈希校验，版本不符会自动跳过，不会破坏安装；需要按新版本的 bundle 重新翻译。

怎么卸载 / 恢复英文？

一键安装包与补丁包都附带「还原英文.bat」，从安装时的备份完整还原。便携版直接删目录即可。

为什么第一次启动要等一分多钟？

Autopsy（NetBeans 平台）会把合并后的菜单结构缓存起来。清空缓存后首次启动需要重建，约 60–90 秒，之后恢复正常速度。
