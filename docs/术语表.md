## 不翻译

- **产品/厂商**：Autopsy、Sleuth Kit、NetBeans、PostgreSQL、Solr、Cyber Triage、ICEpdf、OpenCV、FFMpeg、Google Earth、HxD、Plaso、RegRipper、YARA
- **算法/格式**：MD5、SHA-1、SHA-256、EXIF、JPEG、PNG、MP4、NTFS、FAT、APFS、ext4、LVM、UTF-8
- **技术标识**：URL、HTML、XML、JSON、CSV、SQLite、MIME、Regex、GUID/UUID、API、CPU/RAM
- **字体名**：Helvetica、Courier、Times、Serif、SansSerif、Monospaced、Dialog
- **Linux 发行版**：`Linux（Ubuntu）`、`Linux（Debian）` 等，保留原文
- **快捷键串**：`C-C`、`S-F12`、`M-F4`、`Ctrl+P`

## 标点与转义

1. 中文句内用全角标点（，。：；），括号用中文括号。
2. 标签式文案（`Comment:`）译成全角冒号结尾：`备注：`。
3. **反斜杠转义必须原样保留**：`\n`、`\t`、`\:`、`\\`。写进 properties 时值仍是字面 `\n`，不能变成真换行。
4. 助记符统一写成 `中文(&X)`，一条文案里最多一个 `&`。
5. 文件名、路径、URL 里的字符一律不动。

## 已知特例

| 键 / 值 | 处理 | 原因 |
|---|---|---|
| `NULL="null"` | 不译 | 属性表里显示的 Java null 字面量 |
| `BorderLayout` 方位常量（South、TOP） | 不译 | 代码用字符串比对，翻译会破坏布局 |
| `CTL_PREVIOUS_Mnemonic="B"` | 不译 | 纯助记字母 |
| `gest`（ingest bundle 第 155 行） | 不译 | Autopsy 原厂自带的畸形行，保持与基线一致 |
